Maquette interactive — Aperçu « goutte d'eau » dans la gouttière

Alternative mobile au split view : l'icône d'aperçu vit dans la gouttière, le rendu s'ouvre dans un popup mini-téléphone qui se repositionne dynamiquement pour ne jamais couvrir la ligne où l'utilisateur tape.

Ce que démontre la maquette

  1. Œil dans la gouttière — pas de split view : l'icône d'aperçu est posée sur la rangée de la balise racine (déjà le comportement « œil au caret » de l'éditeur).
  2. Popup goutte d'eau — la carte en verre pointe vers l'icône ; le coin arrondi asymétrique forme la goutte.
  3. Mini téléphone — la preview XML (ou Compose) est rendue dans un châssis miniature.
  4. Dynamique anti-recouvrement — cliquez dans le code : le caret se déplace et le popup esquive la zone de frappe (au-dessus / en dessous), tige de liaison conservée.
  5. Onglets XML / Compose + badge « rendu vivant » (le rendu suit l'édition).
Astuce : cliquez sur une ligne de code pour y poser le caret — le popup se décale pour dégager la zone de frappe. Re-tapez sur l'œil pour refermer.
Maquette de discussion (aucune logique de production) — concept proposé pour l'éditeur : GutterView → icône preview → popup ancré non modal, repositionnement fluide borné à la ligne tapée, fermeture au tap extérieur. Le rendu réel (XML gonflé / arbre Compose simulé) vivrait derrière la même carte.
